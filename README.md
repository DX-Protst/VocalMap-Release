# VocalMap 官方正式版 🚀

欢迎来到 VocalMap 的首个正式商业版本！这是一款专为声乐教学、歌手训练和专业音频制作打造的桌面级声乐诊断与音轨分离工作站。

在经历了一系列的底层架构重构与极限性能压榨后，我们为你带来了目前最先进的本地化 AI 音频处理体验。

## 🌟 核心亮点功能

### 1. 实时声学多维诊断引擎
利用零延迟的高性能信号分析算法（YIN音高追踪变体 + H1-H2共鸣度评估），VocalMap 能够通过你的麦克风实时捕捉并解析声音特征。
*   **六维雷达诊断(Pro版本功能)**：实时分析音准、稳定度、共鸣度、纯净度等发声指标。
*   **毫秒级动态波形**：底噪强效抑制，可视化你的每一次气息吐纳。

### 2. 录音棚级专业音轨分离 (Pro版本功能)
搭载了当前 SOTA 级别的 **BS-RoFormer** 深度学习分离模型。
*   **卡拉OK 人声/伴奏分离**：一键剔除原唱，保留极度纯净的伴奏与和声。
*   **全能 6 轨道乐器分离**：将混合混音精准解剖为 人声、钢琴、吉他、贝斯、鼓组 与 其他。
*   **绝对的数据安全**：纯本地分离，不上传服务器，保证个人数据安全
