# VocalMap 官方正式版 🚀


欢迎来到 VocalMap 的正式商业版本！这是一款专为声乐教学、歌手训练和专业音频制作打造的桌面级声乐诊断与音轨分离工作站。

在经历了一系列的底层架构重构与极限性能压榨后，我们为你带来了目前最先进的本地化 AI 音频处理体验。最新版本全面进化，让您的每一次发声都能留下具象的痕迹！

## 🌟 核心亮点功能

### 1. 进阶靶向发声训练营 (全新重磅上线)
摒弃无目的的瞎唱，系统将基于您选择的标准声部（或高度自由的**自定义音域**），为您动态生成极具针对性的 **6 大渐进式声学练声关卡**：
*   **3 秒动态预判运镜 (Look-ahead Camera)**：彻底解决大跨度音阶（如从胸声直飙头声）导致目标飞出屏幕的视觉盲区，相机视野平滑智能跟随，训练无死角。
*   **100ms 视觉抗延迟补偿算法**：底层重构了“视听同步”逻辑。钢琴准时播放，判定方块巧妙退后 100 毫秒以完美抵消麦克风与系统的收音计算延迟，感受极致精准的命中手感。
*   **录音棚级双轨压限引擎**：内置 Web Audio 动态压限器 (Dynamics Compressor)，彻底解锁并放大了钢琴提示音的极限声量，再大声也圆润厚实，告别失真爆音 (Hard Clipping)。

### 2. 实时声学多维诊断引擎
利用零延迟的高性能信号分析算法（YIN 音高追踪变体 + H1-H2 共鸣度评估），VocalMap 能够通过你的麦克风实时捕捉并解析声音特征。
*   **六维全息诊断雷达 (Pro 版本功能)**：毫秒级抓取音准、稳定度、共鸣度、纯净度等高阶发声指标，甚至能精准捕捉专业级颤音（Vibrato）并独立评分。
*   **动态复盘回放 (全新升级)**：所有演唱轨迹均可一键打包为 `.vmap` 项目文件。回放时视角中心会自动锁定当前音高，配合高精度的白色基准点与纵向标尺，让你像拿放大镜一样看清每一次气息抖动。
*   **一键极速离线分析 (全新升级)**：对于已有的音频干声，无需再傻傻“播放并录制”。直接导入文件，引擎瞬间完成全局透视分析，并直接吐出包含指导建议的综合诊断报告！
*   **高清长图留存**：一键无缝导出暗黑质感的高清长图诊断报告，拒绝背景发灰或内容裁切，成果分享一气呵成。

### 3. 录音棚级专业音轨分离 (Pro 版本功能)
搭载了当前 SOTA 级别的 **BS-RoFormer** 与 **Logic-RoFormer** 深度学习分离模型。
*   **卡拉OK 人声/伴奏分离**：一键剔除原唱，保留极度纯净的伴奏与和声。
*   **全能 6 轨道乐器分离**：将混合混音精准解剖为 人声、钢琴、吉他、贝斯、鼓组 与 其他。
*   **绝对的数据安全**：纯本地 GPU/CPU 推理，不上传服务器，绝无数据泄露风险。

### 4. 次世代极客质感交互
*   全面采用液态玻璃（Liquid Glass）高质感 UI，并包含暗色/亮色双模式。
*   所有交互动效附带平滑渐变反馈；**最新版已全局死锁黄金比例窗口（1200x800），完美规避缩放与拉伸导致的排版灾难**，让工具的使用成为一种沉浸式的享受。
*   **独立的无遮挡激活/状态面板**：彻底重构了 Pro 权限激活与状态查看逻辑，摒弃了传统的全局遮罩（Overlay），改为全尺寸独立工作区（Workspace）平滑流转。在系统设置中更可直接查验精确的初次激活时间及剩余有效期。

### 5. 全球化多语言与无感更新体验 (全新重磅升级)
*   **中/英双语模式与持久缓存**：新增系统语言自动识别（首次启动根据系统区域设置自动初始化为中文/英文）并持久化缓存用户选择。所有的功能界面、高级参数调节面板以及**完整的使用帮助与诊断手册**都已实现 100% 的多语言本地化。
*   **无感弹窗式 OTA 升级**：顶部导航栏升级小字提示已全面移除。升级进度、下载百分比、更新失败警告以及重启引导均改用精美的 Toast 弹窗通知。升级说明窗口排版已彻底重构，加入高度适配的滚动条，彻底解决内容溢出与排版错乱的问题。

### 6. 本地安全网关与隐私防护 (全新安全升级)
为了保护用户隐私（如麦克风采集的声乐数据及个人音频）以及防止主机的显卡/CPU 计算资源被恶意第三方软件非法越权调取，我们重构了进程通信网络，全面接入了本地安全网关体系：
*   **动态随机端口隔离**：每次启动应用时，程序会自动从系统分配当前空闲的随机端口绑定本地后台，彻底摒弃了固定端口（如5050）的通信方式。这有效阻断了其他本地恶意软件通过监听固定端口对麦克风实时音频流、演唱诊断数据的越权窃听与流量拦截，也完美解决了多开程序时的端口抢占冲突。
*   **内联网防嗅探令牌 (API Token)**：在 Tauri 主窗体与本地 Python 声学推理引擎之间，强制启用了动态生成的高强度加密 Token 握手校验。其他本地后台进程、恶意脚本或局域网内的设备即使嗅探到了后台端口，在没有正确安全令牌的情况下，也会被立刻拒绝访问。这能完全防止第三方恶意程序越权调用您的本地 AI 引擎，杜绝您的 GPU/CPU 算力与电力资源被后台窃用（如用于非法挖矿或大模型推理）。
*   **时钟回滚与算法指纹校验**：通过加密校验本地时钟状态与底层算法指纹，确保系统安全日志与本地依赖的更新时序一致，防止第三方调试工具或逆向木马非法注入及篡改本地声学引擎的运行状态，最大程度保障您的系统底层安全。
