# VocalMap 官方正式版 🚀


欢迎来到 VocalMap 的正式商业版本！这是一款专为声乐教学、歌手训练和专业音频制作打造的桌面级声乐诊断与音轨分离工作站。

在经历了一系列的底层架构重构与极限性能压榨后，我们为你带来了目前最先进的**纯粹、极简、零延迟**本地化 AI 音频处理体验。最新版本全面进化，让您的每一次发声都能留下具象的痕迹！

## 🌟 核心亮点功能

### 1. 全方位纯 Rust IPC 驱动架构 (全新重磅升级)
我们彻底废弃了曾经沉重且极易被破解的 Python FastAPI 框架，将其底层架构 100% 迁移至 Tauri 原生 Rust IPC 环境：
*   **10MB 极限身材**：告别动辄 500MB 的笨重安装包，由于剔除了所有本地捆绑的 Python 依赖，新版安装包体积直接降维打击至 **< 10MB**！所有的 AI 运行环境将在首次使用时通过云端“按需极速拉取”。
*   **零延迟内存交互**：完全抛弃了 WebSocket 网络传输开销，声学引擎现在直接通过内存级 Rust IPC 与 WebAudio 通信，音高追踪与诊断延迟降低至微秒级。
*   **无法攻破的黑盒安全**：再也不用担心本地端口被恶意监听！核心鉴权、DSP 解析器（包括高精度 YIN 算法）现已全部被重写为 Rust 原生机器码，带来不可阻挡的逆向防爆屏障。

### 2. 进阶靶向发声训练营
摒弃无目的的瞎唱，系统将基于您选择的标准声部（或高度自由的**自定义音域**），为您动态生成极具针对性的 **6 大渐进式声学练声关卡**：
*   **3 秒动态预判运镜 (Look-ahead Camera)**：彻底解决大跨度音阶（如从胸声直飙头声）导致目标飞出屏幕的视觉盲区，相机视野平滑智能跟随，训练无死角。
*   **100ms 视觉抗延迟补偿算法**：底层重构了“视听同步”逻辑。钢琴准时播放，判定方块巧妙退后 100 毫秒以完美抵消麦克风与系统的收音计算延迟，感受极致精准的命中手感。
*   **录音棚级双轨压限引擎**：内置 Web Audio 动态压限器 (Dynamics Compressor)，彻底解锁并放大了钢琴提示音的极限声量，再大声也圆润厚实，告别失真爆音 (Hard Clipping)。
*   **新增【自定义靶向特训】入口**：彻底打通从分离到特训的生态闭环！您可以导入由 AI 音轨分离功能提取的专属 `.tmap` 自定义关卡文件，针对性攻克您最想练的任意高难度歌曲片段。

### 3. 实时声学多维诊断引擎
利用零延迟的 **Rust 原生高性能信号分析算法**（YIN 音高追踪变体 + H1-H2 共鸣度评估），VocalMap 能够通过你的麦克风实时捕捉并解析声音特征。
*   **六维全息诊断雷达 (Pro 版本功能)**：毫秒级抓取音准、稳定度、共鸣度、纯净度等高阶发声指标，甚至能精准捕捉专业级颤音（Vibrato）并独立评分。
*   **动态复盘回放**：所有演唱轨迹均可一键打包为 `.vmap` 项目文件。回放时视角中心会自动锁定当前音高，配合高精度的白色基准点与纵向标尺，让你像拿放大镜一样看清每一次气息抖动。
*   **高清长图留存**：一键无缝导出暗黑质感的高清长图诊断报告，拒绝背景发灰或内容裁切，成果分享一气呵成。

### 4. 录音棚级专业音轨分离 (Pro 版本功能)
搭载了当前 SOTA 级别的 **BS-RoFormer** 与 **Logic-RoFormer** 深度学习分离模型。
*   **卡拉OK 人声/伴奏分离**：一键剔除原唱，保留极度纯净的伴奏与和声。
*   **全能 6 轨道乐器分离**：将混合混音精准解剖为 人声、钢琴、吉他、贝斯、鼓组 与 其他。
*   **双核导出特训包**：分离完毕后，系统不仅能导出用于回放的 `.vmap` 标准复盘包，更可基于人声干音自动提取离散的块状音高序列，导出为 `.tmap` 靶向特训关卡。
*   **绝对的数据安全**：纯本地 GPU/CPU 推理，不上传服务器，绝无数据泄露风险。

### 5. 次世代极客质感交互
*   全面采用液态玻璃（Liquid Glass）高质感 UI，并包含暗色/亮色双模式。
*   所有交互动效附带平滑渐变反馈；**支持响应式自适应布局**，无论是大屏高分辨率还是窄窗/竖屏，画布及核心仪表均能基于 Flexbox 弹性填充和防清空重绘，完美规避排版灾难，让工具的使用成为一种沉浸式的享受。
*   **独立的无遮挡激活/状态面板**：彻底重构了 Pro 权限激活与状态查看逻辑，摒弃了传统的全局遮罩（Overlay），改为全尺寸独立工作区平滑流转。

### 6. 全球化多语言与无感更新体验
*   **中/英双语模式与持久缓存**：新增系统语言自动识别（首次启动根据系统区域设置自动初始化为中文/英文）并持久化缓存用户选择。所有的功能界面、高级参数调节面板以及**完整的使用帮助与诊断手册**都已实现 100% 的多语言本地化。
*   **无感弹窗式 OTA 升级**：顶部导航栏升级小字提示已全面移除。升级进度、下载百分比、更新失败警告以及重启引导均改用精美的 Toast 弹窗通知。

## 📱 移动端（Android）开发可行性评估

基于 VocalMap 当前的 **Tauri v2 + Rust 原生 DSP + Web Audio 前端** 架构，我们对将其移植到 **Android 移动端** 进行了技术可行性评估：
* **核心可行**：Tauri v2 具备完善的 Android 原生编译链支持；前端 UI 的响应式自适应布局与 Canvas 动态绘制对移动端友好；核心的 Rust 原生 DSP 引擎（YIN 算法等）可无损编译为 Android 机器码运行，性能极佳。
* **明确裁剪**：**AI 音轨/伴奏分离功能（BS-RoFormer 模型）由于对 PyTorch 框架及 GPU/CPU 算力依赖极重，确定不移植到手机端**，在移动端版本中该模块将被隐藏/禁用。
* **需重构的桌面依赖**：设备指纹识别（`machine-uid` 库不支持 Android，需改用 native 接口获取 `ANDROID_ID`）、文件选择器（需适配 Android Scoped Storage 分区存储）以及自动更新（需停用 Tauri Desktop Updater，改用应用商店分发）。

完整的移动端移植技术分析与重构指南，请参阅：[Android 移动端移植可行性评估报告](docs/ANDROID_FEASIBILITY.md)
