VocalMap 使用帮助与诊断手册

实时声学监视与特征解析

VocalMap 拥有毫秒级的实时声学诊断引擎。在“实时监视”模块，您可以实时观察嗓音的动态表现，生成声学指纹数据。

1. 启动监视与录制

首先点击导航栏右侧的“启动引擎”，然后对着麦克风发声或歌唱。系统将以极低延迟绘制出音高轨迹曲线。

2. 零延迟项目回放

点击左下角的“开始监视录制”，对着麦克风发声或歌唱，点击“结束监视录制”后，回放控制条将自动显现。您可点击“播放/暂停”复盘刚刚的演唱，拖拽进度条能随意跳跃。回放时视窗会自动聚焦，鼠标中心纵向白线锁定当前播放时间点的精确 MIDI 音高与分数值。

3. 导入与导出 (.vmap)

录制结束后，点击右下角的“导出”按钮，可将完整的录音波形和声学曲线打包保存为专属的 `.vmap` 项目文件。日后点击“导入”即可完美复原历史监视会话进行二次复盘。

实时声学指纹指标说明

音高 (Pitch)

使用基于 YIN 音高追踪的变体算法，毫秒级捕捉基频并转化为十二平均律 MIDI 唱名。

机能 (H1/H2)

分析基音（H1）与第一泛音（H2）的相对能量比，评估声带闭合程度与共鸣度。

纯净 (HNR)

谐噪比评估。音质越纯净值越高（如 20dB 以上），沙哑或漏气声会导致数值下降。

稳定 (Jitter)

微观音高抖动率。评估声带振动的周期稳定性，普通演唱应控制在 1.5% 以下。

Pro 核心功能操作指南

专业版解锁了全息诊断雷达大脑与 SOTA 级别的 RoFormer 音轨分离引擎，是声乐教学和混音后期制作的终极利器。

1. 专业歌声全息诊断与雷达图

在“Pro 核心功能 -> 歌声检测”子页面，您可以点击“麦克风实时检测”开始录制长乐句，或直接“导入音频检测”（算法会在后台执行极速毫秒级离线全量提取）。分析完成后，系统将呈现一个五维声学雷达图，包含音准命中率、机能共鸣、纯净度、稳定度和颤音评分的精确统计。

2. 导出高清长图报告

诊断报告出炉后，您可以点击“导出报告长图”。系统将自动生成无损、超清的长截图 PNG 报告，完美保存雷达图 and 各项量化分数，方便分享给社交平台或进行教学存档。

3. 录音棚级高精度音轨分离

针对音频提取和伴奏剥离，提供两种业界顶尖的深度学习神经网络模型：

  • 6-Stem 乐器分离 (Logic-RoFormer)：将音频剥离为伴奏、人声、鼓、贝斯、钢琴、吉他等独立声部。
  • 干声与和声分离 (BS-RoFormer Karaoke)：将音频剔除原唱，提取极致纯净的主唱干声与背景和声。

在分离面板顶部可快捷切换“GPU 加速”（显存需 >6GB，推理极速）或“CPU 兼容”模式。

4. 靶向训练营动态运镜

在“Pro 核心功能 -> 关卡训练营”中，您可以先选择自己的所属声部（如男高音、女低音等），系统将自动为您规划最适合的练习音域。

六大进阶关卡包含：
1. 稳定音高：练习在基础发声中的音准保持。
2. 连音爬音：练习气息支撑下平滑的音阶过渡。
3. 布鲁斯转音：训练声带灵活性和快速反应。
4. 颤音控制：练习喉头放松，保持声音的波动美感。
5. 真假声断音：训练声带边缘振动与快速闭合。
6. 综合大考：结合以上所有技巧的综合实战训练。

智能视野跟随：训练期间，您无需任何手动操作。在遇到跨度极大的高低音时，画面会自动提前平滑移动，为您提供最清晰的练习视野。

声学引擎底层参数调节说明

点击导航栏右上角的“引擎调节”可唤起参数配置面板。针对不同的使用环境和录音硬件，微调这三个核心阈值能将识别精度发挥到极致：

响度激活门限 (Loudness Gate)

推荐基准值: 8
这是触发系统开始捕捉音高的最低音量门限。如果您处于喧闹的教学班级或房间，或者您的麦克风有强烈的交流电嗡嗡声底噪，建议将该值调高（如 12 至 15），从而有效防止环境音导致仪表盘无辜跳动。

发声纯净度门限 (Clarity Threshold)

推荐基准值: 0.65
用于控制系统对“漏气发声/气泡音/呼吸声”的捕获灵敏度。如果您想做气声哼唱、弱音或边缘振动（Vocal Fry）的精细测量，可将此值调低（如 0.4 至 0.5）。若是在普通的现场歌唱检测中，建议维持 0.65 或更高，以过滤换气时的气流声干扰。

底噪极速追踪门限 (Noise Tracking)

推荐基准值: 20
控制降噪追踪器的敏感深度。当外界噪音或音频背景声的响度降到该临界点以下时，底层降噪追踪器会判定此时“歌手已停止发声”，在数毫秒内将信号强制静音归零。这能杜绝音高曲线上出现莫名的“尾音拖尾”杂点。

声乐教学与分析高阶独门技巧

终极教学秘籍：如何完美测量一首现成歌曲的歌手精确音高？ 现成发行的流行乐曲中由于带有宏大的管弦乐、吉他或鼓声伴奏，如果直接导入声学检测，乐器的基频会极大干扰 YIN 追踪器，导致音高轨迹频繁乱跳或根本无法锁定。

完美破解流线 ： 先将音轨导入到 Pro 核心功能 -> 音轨分离，启动“干声与和声分离”，提取出纯人声（Vocals Stem）并保存到本地。随后，将该人声 WAV 文件导入 歌声检测 -> 导入音频检测 -> 存为回放项目 -> 实时监视 -> 导入。这样，系统测得的将是绝无干扰、极其平滑且 100% 对应歌手本人的真实物理音高与颤音轨迹！
靶向得分换算机制 训练营的得分不仅考量您的绝对音准，还引入了瞬态响应时间和维持稳定度的双重动态扣分换算。当您的音高完全击中靶向方块中心且持续稳定，将获得满分；若音高游离于边缘或发生明显抖动（Jitter过高），系统将动态扣减分值。高频度练习此机制能显著提升声带的闭合控制力。
Soprano/Baritone 各声部物理共鸣基准表 每个声部在进行跨越换声区（Passaggio）的训练时，其物理共鸣焦点是不同的。以 女高音 (Soprano) 为例，核心换声点通常在 F#5 附近，胸声主要集中在 C4-F4，进入头声的靶心多为 C5 以上；而 男中音 (Baritone) 的换声点则落在 Eb4-E4，其低频胸区（G2-C3）是巩固下盘机能的关键。您可以在“三类共鸣”等关卡中体验该基准表的靶向映射。

常见问答 Q&A

Q: 运行音轨分离时，首次启动或推理需要多长时间？

A: 所有的核心 AI 模型权重文件和便携式推理库已由系统内置的动态下载管理器在首次启动时拉取并校验完毕。当您第一次在分离面板中启动推理时，Python 引擎需要一些时间将大模型从磁盘加载到显存/内存中，请耐心等待；加载完成后，后续的分离运算将是完全本地化、极速无感的高速离线推理。

Q: 音轨分离提取后，为什么保存或下载总是卡顿？

A: 之前版本的 Tauri JS-to-Rust 二进制桥接在传输大体积无损 WAV 文件时会导致 UI 短暂假死。VocalMap v2.8.2引入了本地 FastAPI 零拷贝（Zero-Copy）直写技术，剥离出来的音轨由 Python 引擎直接以物理速度写入目标磁盘，彻底避免了内存占用与界面响应迟钝。先前版本用户请先行更新至v2.8.2以上版本即可解决。

Q: 为什么无法显示软件版本号，或界面有卡死感觉？

A: 这通常代表本地 Python 诊断引擎被安全软件（如 360 或 Windows Defender）拦截、或者 WebSocket 通信接口（5050 端口）被其他本地代理软件占用。请尝试将软件加入杀毒白名单，并确保没有其他应用程序占用 5050 端口。
