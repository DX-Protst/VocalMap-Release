# VocalMap

桌面级声乐诊断与音轨分离工作站。让你的每一次发声，都能留下具象的痕迹。

## 核心亮点功能

- **实时声学多维诊断**
  集成 YIN 音高追踪与 H1-H2 共鸣度评估。六维全息诊断雷达毫秒级抓取颤音与发声指标，支持干声一键极速离线分析并无缝导出高清暗黑长图。

- **进阶靶向发声训练营**
  基于标准声部或自定义音域生成 6 大渐进式练声关卡。配备 3 秒动态预判运镜和 100ms 视觉抗延迟补偿，录音棚级双轨压限引擎避免发声失真爆音。

- **录音棚级专业音轨分离**
  搭载 SOTA 级 BS-RoFormer 与 Logic-RoFormer 深度学习模型。完美实现人声/伴奏二轨及六轨乐器（人声、钢琴、吉他、贝斯、鼓组、其他）纯本地超清分离。

- **次世代极客质感交互**
  全面采用液态玻璃（Liquid Glass）高质感 UI 交互，固定黄金比例窗口（1200x800），平滑过渡深浅主题。

- **本地网关与安全隐私**
  绝不上传任何音频或个人数据。每次启动分配动态随机端口绑定，启用 API Token 握手校验，杜绝数据泄露。
